# avanbraeckel.github.io — site

Next.js 16 static export, deployed to GitHub Pages by `.github/workflows/deploy.yml`.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # → out/
npm start        # serve out/
npm test
```

See the repository's `CLAUDE.md` for architecture and conventions, and `PLAN.md` for the design rationale.
